# Accessibility and web interface guidelines

Based on Vercel's Web Interface Guidelines (`vercel-labs/web-interface-guidelines`, skill `web-design-guidelines`). Review UI changes against it; `jsx-a11y` rules in oxlint catch part of it automatically.

## Accessibility

- Icon-only buttons need `aria-label`; decorative icons need `aria-hidden="true"`.
- Form controls need a `<label>` or `aria-label`; labels are clickable (`htmlFor` or wrapping).
- Use `<button>` for actions and `<a>`/`<Link>` for navigation. Never `<div onClick>`.
- Semantic HTML before ARIA: `<main>`, `<header>`, `<nav>`, `<section>`, `<ul>`/`<li>`.
- One `<h1>` per screen, headings in order. A skip link jumps to `<main>`.
- Async updates (validation errors, countdown warnings, toasts) use `role="alert"` or `aria-live="polite"`.
- Images have `alt` (`alt=""` when decorative).
- Drag/swipe gestures need a keyboard or tap alternative.
- No `autoFocus` (lint-enforced). Move focus deliberately: dialogs focus their first control through the dialog's `initialFocus`.

## Focus

- Every interactive element has a visible `focus-visible:` style. Never remove the outline without a replacement.
- Use `:focus-visible`, not `:focus`. Group compound controls with `:focus-within`.

## Forms

- Inputs have `name`, `autocomplete` (`off` for non-auth fields), the right `type`/`inputmode`, `spellCheck={false}` for names and codes.
- Never block paste. Placeholders end with `…` and show an example.
- Errors sit next to the field. Warn before leaving unsaved changes.

## Motion

- Honour `prefers-reduced-motion`: CSS animations are disabled in a reduced-motion media query and `motion` uses `reducedMotion="user"`.
- Animate `transform` and `opacity` only. Never `transition: all` (list properties). Set a correct `transform-origin`. Animations stay interruptible.

## Typography and content

- `…` not `...`; curly quotes in prose; non-breaking space between number and unit.
- Loading states end with `…`. Numbers in columns use `tabular-nums`. Headings use `text-balance`/`text-pretty`.
- Text containers handle long content (`truncate`, `line-clamp-*`, `break-words`); flex children that truncate need `min-w-0`. Handle empty states.
- Dates and numbers go through `Intl.*`, never hard-coded formats. Brand names get `translate="no"`.

## Touch and layout

- `touch-action: manipulation` on interactive elements; set `-webkit-tap-highlight-color` deliberately.
- Modals/sheets use `overscroll-behavior: contain`.
- Full-bleed layouts respect `env(safe-area-inset-*)`.
- Do not disable zoom (`user-scalable=no`, `maximum-scale=1`).

## Theming

- `color-scheme` follows the theme (`dark` on `<html>` in dark mode), and `<meta name="theme-color">` matches the page background.

## Images and performance

- `<img>` has explicit `width` and `height`. Lists over 50 items are virtualised or use `content-visibility: auto`. No layout reads (`getBoundingClientRect`) during render.

## Navigation and state

- Destructive actions need a confirmation or undo. Links keep Cmd/Ctrl+click behaviour.

## Review output

Findings are listed as `file:line - issue`, grouped by file. A file with none is `✓ pass`.
