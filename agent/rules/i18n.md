# i18n: flat locale files (`a.b.c`)

## Rule

- `src/i18n/locales/*.json` is a **single-level** object. Keys contain dots, values are strings. No nested objects.
- `src/i18n/index.ts` sets `keySeparator: false`, so the dot is part of the key.
- `en.json` and `vi.json` always have the **same keys** in the same order.
- All visible text goes through `t('key')`; no hard-coded strings in components.

## Right

```json
{
  "setup.errors.noInfiltrator": "Add at least one Undercover or Mr. White.",
  "play.cards.card": "Card {{n}}"
}
```

## Wrong

```json
{
  "setup": { "errors": { "noInfiltrator": "…" } }
}
```

## Key naming

- Shape `area.screen.item`: `groups.edit.title`, `play.result.outRound`.
- Same prefix for the same screen, so one grep finds them all.
- Plurals use i18next suffixes (`_one`, `_other`); interpolation is `{{count}}`.
- Dynamic keys (``t(`roles.${role}`)``) must exist for every possible value (for roles: `roles.000_CIVILIAN`, …).

Renaming an id (such as a role) means renaming every dynamic key built from it: grep for `${` inside `t(` calls.

## When adding or changing text

1. Add the key to both files.
2. Keep them grouped by prefix.
3. Run `bun run build`, then open the UI in both languages to make sure no raw key shows.
